# Contributing

Thank you for interest in the Astudio WYSIWYG Rich HTML Editor.

Copyright remains with **Astudio LLC**. This is source-available proprietary freeware, not OSI-approved open source. See [LICENSE.md](LICENSE.md).

## How to contribute

1. Fork the official GitHub repository.
2. Keep `LICENSE.md`, copyright notices, and Astudio attribution.
3. Change the editor in **`src/`**. Then copy the same four files into **`dist/`** so they stay identical (CI checks this).
4. Do not minify, rename public APIs (`ClassicEditor`, `FreeEditor`), or change HTML output unless a maintainer asked for that.
5. Open a pull request against `main` with a short description of the change.

## Issues

Use the GitHub issue templates for bugs and feature ideas. Do not file public issues for undisclosed security problems — see [SECURITY.md](SECURITY.md).

Commercial integration, customization, and paid updates: [https://astudio.am/en](https://astudio.am/en)

## Code of conduct

Be respectful. Do not submit stolen code, malware, or content that violates the law.
