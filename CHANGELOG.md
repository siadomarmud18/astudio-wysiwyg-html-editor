# Changelog

## 1.3.1 — 2026-09-09

First public GitHub layout for the Astudio WYSIWYG Rich HTML Editor base version.

- Layout: `src/`, `dist/`, `examples/basic/`, `docs/`, `tests/`, `.github/`
- Copy `dist/` onto a host (for example `public/vendor/astudio-editor/`)
- GitHub issue templates, CONTRIBUTING.md, and CI that checks JS syntax and `src` vs `dist`
- Editor features, toolbar, HTML output, and Phase 3 tools are unchanged
